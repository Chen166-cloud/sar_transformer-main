Overall architecture of the proposed Trans-SAR-based despeckling model. (a) Gray components denote inherited operators; colored components denote the extensions used in this work. Four encoder skips enter learned decoder fusion. Six stage-specific Fourier residual refinement (FDR) blocks and a shared latent guidance map support reconstruction. Exact inverse mapping precedes intensity residual compensation. Shapes are H x W x C for a normalized input Y in [0,1]. (b) Masked post-adaptation freezes the encoder and updates the reconstruction modules; inference uses unmasked observations.
