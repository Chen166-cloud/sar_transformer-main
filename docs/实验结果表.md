roi选择算法

这里的“固定 ROI”不是所有图片使用同一组坐标，而是：

> 每张真实 SAR 图像各自选出5个 ROI；坐标一旦选定，Noisy、所有基线和 Ours 都必须使用这5个相同位置。

具体选择过程如下：

1. 将图像固定映射到强度域 \([0,1]\)，不做逐图归一化。
2. 将一张 \(256\times256\) 图像按步长32扫描，得到64个不重叠的 \(32\times32\) 候选区域。
3. 排除：
   - 平均强度小于0.03的过暗区域；
   - 像素值为0或1的比例超过5%的区域。
4. 对每个候选区域计算：

\[ S_{\mathrm{ROI}}=\frac{\operatorname{Var}(I_{\mathrm{ROI}})} {\operatorname{Mean}(I_{\mathrm{ROI}})^2} \]

这个值也就是平方变异系数，越小说明区域内部越平坦、越接近均匀区域。

1. 按 \(S_{\mathrm{ROI}}\) 从小到大排序，选择前5个区域。
2. 保存这5个区域的坐标，后续所有方法都只能在相同坐标计算：

\[ \mathrm{ENL}=\frac{\mu^2}{\sigma^2} \]

例如，某张图选出的坐标可能是：

| ROI   | x    | y    | width | height |
| ----- | ---- | ---- | ----- | ------ |
| ROI-1 | 64   | 32   | 32    | 32     |
| ROI-2 | 160  | 96   | 32    | 32     |
| ROI-3 | 0    | 192  | 32    | 32     |
| ROI-4 | 96   | 224  | 32    | 32     |
| ROI-5 | 192  | 64   | 32    | 32     |

这些只是示例；每张图的实际坐标可能不同。

这样做的意义是避免“为某个方法专门挑选看起来最好的平坦区域”。ROI仅根据原始 Noisy 图像选择一次，之后不因方法和实验结果改变。

本机测试集共有592个 patch，因此总共得到：

\[ 592\times5=2960\text{ 个 ROI} \]

论文中的 `ENL median [IQR]` 是对这2,960个固定 ROI 的 ENL进行统计。具体实现位于 [icsps2026_metrics.py (line 272)](/Users/tim/sar_transformer-main/icsps2026_metrics.py:272)，实际坐标保存在 [real_enl_roi_manifest.csv](/private/tmp/icsps26-real-qc-local/real_enl_roi_manifest.csv)。
